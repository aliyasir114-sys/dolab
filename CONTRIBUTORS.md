## About GitHub's Contributors graph / عن رسم المساهمين في GitHub

GitHub generates the repository's Contributors graph from commits attributed to GitHub accounts. This acknowledgment page does not change that graph and does not add artificial commit attribution.

ينشئ GitHub رسم المساهمين من commits المنسوبة إلى حسابات GitHub. صفحة الشكر هذه لا تغيّر الرسم ولا تنسب commits مصطنعة لأي شخص.
