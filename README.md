# دولاب | DOLAB

دولاب إلكتروني ذكي: يسجّل ملابسك، يقترح إطلالات يومية مما تملك، ويتيح تجربتها افتراضياً، مع سوق داخلي للملابس وقسم لتراث أزياء العالم.
A smart digital wardrobe: catalogue your clothes, get daily outfit suggestions from what you own, try them on virtually, plus an in-app fashion market and a world-heritage dress section.

**الحالة / Status:** نموذج تفاعلي للشاشات (تصميم فقط، لا يوجد كود تطبيق بعد) — design prototype only, no application code yet.

## الوظائف الأساسية / Core features

1. **الدولاب الذكي** — استخراج القطع وألوانها من صور المستخدم، مع تجنّب الصور ذات الفلاتر، ودرجة ثقة وتأكيد يدوي للون.
2. **بطاقة القطعة** — الحالة (متاح، في الغسيل، في الصيانة، مخزن، للبيع، تم التبرع به، مفقود)، مرات الارتداء، العمر منذ الشراء.
3. **مستشار الأزياء** — اقتراحات يومية من الملابس المتاحة حسب المناسبة والطقس وسجل الارتداء.
4. **الملف الشخصي** — الطول، الوزن، المقاسات، شكل الجسم والوجه.
5. **التجربة الافتراضية** — تجربة القطعة على صورة المستخدم (مرحلة متقدمة).
6. **تراث العالم** — الأزياء التقليدية حسب المناطق.
7. **سوق دولاب** — للأفراد والمتاجر والمصممين، ملابس وموضة فقط، والنشر بعد المراجعة.
8. **التبرع** — تحويل قطع من الدولاب إلى تبرع.
9. **لوحة التحكم** — مؤشرات المستخدمين والدولاب والسوق والموضة.
